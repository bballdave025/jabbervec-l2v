# Decisions

## Repo name

Chosen: `jabbervec-l2v`

Rationale:

- `JabberVec` signals Lewis Carroll / Jabberwocky / literary nonsense.
- `l2v` keeps the Letter2Vec concept visible.
- Package name is `jabbervec` for ergonomic imports.

## License

Chosen: MIT License.

Rationale: permissive, simple, good for learning projects, easy to reuse.

## First corpus

Start with `examples/tiny_corpus.txt`, then try a local dictionary or public-domain text.

## Anti-perfectionism rule

Do not wait for the perfect corpus. Run the toy experiment first.
